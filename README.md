# HackerRank Solutions in Java

Resoluções de desafios práticos do [HackerRank](https://www.hackerrank.com/) desenvolvidas em **Java**.

---

## Estrutura do Projeto

```text
src/
└── algorithms/    # Soluções dos desafios práticos
```

Cada arquivo dentro do pacote `algorithms` contém a resolução completa de um problema específico da plataforma.

---

## Como Executar

### Pré-requisitos
- **Java JDK** 15 (ou superior)

### Execução via Terminal
Para compilar e executar qualquer uma das soluções:

```bash
# Compilar
javac -d out src/algorithms/<NomeDoArquivo>.java

# Executar
java -cp out algorithms.<NomeDoArquivo>
```
